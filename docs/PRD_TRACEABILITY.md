## Privacy & security (§11)

| Requirement                                                  | Where                                                                                                             |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| No key in source, logs, crash reports or diagnostics         | `redact.rs` applied to every `WispError`, the crash hook and diagnostics; key only in the `x-goog-api-key` header |
| OS-protected secret storage, fail safely                     | `secrets.rs`; vault errors are surfaced, no plaintext fallback                                                    |
| Push-to-talk mic with visible state and stop                 | Dictation/Voice cards, orb `listening` state                                                                      |
| Screen capture only after deliberate action and confirmation | `capture.rs` and the overlay ("nothing is sent until you confirm") plus the attachment chip                       |
| Clipboard event-driven only                                  | `clipboard_read` is only called from an explicit button or shortcut                                               |
| Model output untrusted, validated                            | `tools.rs::validate_call` (deny unknown fields, limits)                                                           |
| No shell execution                                           | No shell tool; shells refused in the allowlist                                                                    |
| Confirm consequential actions                                | `requires_confirmation` (open app/URL, remember); deletes use `ConfirmDialog`                                     |
| Timeouts, bounded retries, size limits, cancellation         | `gemini/mod.rs`, `retry.rs`, `MAX_REQUEST_BYTES`                                                                  |
| Privacy page                                                 | Settings → Privacy, `docs/SECURITY.md`                                                                            |
| No analytics                                                 | `telemetry_opt_in` forced false; the update check is manual only                                                  |

## Errors (§12), non-functional (§13), definition of done (§16), brand acceptance (§24)

| Item                                                                                                                                              | Where / how verified                                                                                                                |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Error states (auth, quota, network, model, permission, rejected action, DB, unexpected)                                                           | `gemini/errors.rs`, `services/errors.ts::presentError`, in-memory DB fallback with a warning, error refs from `WispError::internal` |
| Startup under 3 s after first run, near-zero idle CPU                                                                                             | `--self-test` measures setup time (CI fails the warm run above 3000 ms); animations pause while hidden (`html[data-hidden]`)        |
| Installs without admin                                                                                                                            | NSIS `installMode: currentUser`                                                                                                     |
| Launches on Windows 11                                                                                                                            | Windows CI runs the packaged `wisp.exe --self-test`                                                                                 |
| Automated tests for critical logic                                                                                                                | Rust: `cargo test --workspace`; UI: `npm test`; browser: Playwright                                                                 |
| Dark/Light/System persist; distinct orb states; reduced motion; semantic tokens; legible at scaling; explicit capture states; restrained identity | `tokens.css`, `Orb.tsx`, `orb.test.ts`, `settings.test.tsx` (theme), size setting, Manual: Theme & accessibility                    |
