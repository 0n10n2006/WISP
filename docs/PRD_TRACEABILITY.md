## Privacy & security (§11)

| Requirement                                                  | Where                                                                                                             |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| No key in source, logs, crash reports or diagnostics         | `redact.rs` applied to every `WispError`, the crash hook and diagnostics; key only in the `x-goog-api-key` header |
| OS-protected secret storage, fail safely                     | `secrets.rs`; vault errors are surfaced, no plaintext fallback                                                    |
| Push-to-talk mic with visible state and stop                 | Dictation/Voice cards, notch peek "Listening — release to…", observe-only hold hook                               |
| Screen capture only after deliberate action and confirmation | `capture.rs` and the overlay ("nothing is sent until you confirm") plus the attachment chip                       |
| Clipboard event-driven only                                  | `clipboard_read` only on explicit action; opt-in history skips content marked private                             |
| Model output untrusted, validated                            | `tools.rs::validate_call` (deny unknown fields, limits)                                                           |
| No shell execution                                           | No shell tool; shells refused in the allowlist                                                                    |
| Confirm consequential actions                                | `requires_confirmation` (open app/URL, remember); deletes use `ConfirmDialog`; sleep/restart/shut down confirm    |
| Timeouts, bounded retries, size limits, cancellation         | `gemini/mod.rs`, `retry.rs`, `MAX_REQUEST_BYTES`                                                                  |
| Privacy page                                                 | Settings → Privacy, `docs/SECURITY.md`                                                                            |
| No analytics                                                 | `telemetry_opt_in` forced false; the update check is manual only                                                  |

## Hitodama parity (v0.2)

Hitodama's public feature list (notch dashboard, hold hotkeys, lasso, dictation clean-up, screen pointer,
background agents, "soul") was matched with Wisp's own implementation and design. No Hitodama code, assets or
branding are used.

| Hitodama feature                                                          | Wisp v0.2                                                                                    | Better because                                                                                     | Where / verified                                                                 |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Notch that expands into a dashboard                                       | Sliver → peek → command bar, top-centre of the cursor's monitor, sized to its content        | Folds away on blur/Esc, hides for fullscreen apps, tuckable; peek shows live status                | `windows.rs`, `notch/*`, `dashboard.test.tsx`                                    |
| 8 tabs: Controls, Today, Stats, Clipboard, Apps, Agents, Wallpaper, Power | Same eight tabs                                                                              | Repeating reminders, focus timer that notifies even when closed, grouped process stats, speed test | `screens/dashboard/*`, `dashboard.test.tsx`                                      |
